# 学习空间 · 一站式个性化学习平台

纯前端单文件应用，数据保存在浏览器本地（localStorage + IndexedDB），不联网、无后端、无账号。

## 功能
- 首页：积分 / 等级 / 连胜 / 每日目标 / 薄弱点推荐 / 资料库概览
- 学习：科目 → 章节 → 章节测验（即时判分 + 解析）/ 错题回顾
- 资料库：上传 PDF / PPT / Word / Excel / 图片 / 音视频，收藏网址、写笔记；自定义分类与标签、搜索筛选、关联科目章节、一键打开、学习状态与使用次数
- 计时学习：正计时 + 倒计时，结束即计入时长统计
- 时间统计：7 / 30 / 90 天趋势、科目占比、章节 TOP、时段分布
- 管理题库：单选 / 判断 / 多选，含解析，可编辑删除
- 支持导出 / 导入 JSON 备份与资料包

## 使用
打开页面即用。换设备时用「导出备份 / 导入数据」迁移进度；资料库支持「导出(含文件)/导入资料包」。

## 部署
本仓库通过 GitHub Pages 发布，入口为 index.html。
