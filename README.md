# 学习空间 v1.5 · 一站式个性化学习平台

纯前端单文件应用，数据保存在本机浏览器（localStorage + IndexedDB），不联网、无后端、无账号。

在线使用：https://hsy-china.github.io/learnhub/

## 结构与模块

- 📁 **文件夹树**（顶层 = 学习项目，可无限嵌套）
- 🏷 **标签**（跨文件夹横切，用于筛选与组卷）
- ✅ **学习清单**（可排期：今天/明天/每天/每周几；支持推迟与跳过；完成需手动确认）
- 页面：首页 / 📁 文件夹 / 📂 资料库 / ✅ 学习清单 / ⏲ 计时 / ⏱ 统计

## 资料打开方式

- PDF / 图片 / 音视频 / 文本 → 浏览器直接打开
- **Word(.docx) / Excel(.xlsx) / PPT(.pptx) → 页内弹窗预览**（内置零依赖解析器，离线可用）
- 旧版 .doc / .xls / .ppt → 自动下载后用 Office/WPS 打开
- 网址型文档 → 「在线预览」（微软 Office 在线预览，需公网可访问）
- 想 100% 保真：把 Word/PPT 另存为 PDF 再上传

## 一体化记录

- 右下角常驻 **「▶ 开始学习」**：看纸质书 / 上课 / 用其他 App 学习时一键开始与结束并记账；刷新不丢会话；手机可用 `#start` 快捷方式
- **任务完成即记账**：勾选「计时 / 待办」类清单任务时确认实际分钟数
- **补录**作为兜底入口（计时页 / 统计页底部）
