# 学习空间 v1.0 · 一站式个性化学习平台

纯前端单文件应用，数据保存在本机浏览器（localStorage + IndexedDB），不联网、无后端、无账号。

在线使用：https://hsy-china.github.io/learnhub/

## 结构

- 📁 **文件夹树**：顶层文件夹即学习项目，可无限嵌套；资料与题目都放在文件夹里
- 🏷 **标签**：跨文件夹横切（#易错 #第二遍 …），用于筛选与组卷
- ✅ **学习清单**：可排期的学习流程（看资料 → 做测验 → 错题回顾 → 计时），完成后手动确认

## 模块

首页 / 📁 文件夹（子文件夹 · 资料 · 题目 · 概览）/ 📂 资料库 / ✅ 学习清单 / ⏲ 计时 / ⏱ 统计

## 特色

- 资料支持 PDF/PPT/Word/Excel/图片/音视频/网址/笔记，一键打开，记录打开次数与掌握状态
- 资料 ↔ 题目 双向关联：「出题」即针对该资料建题，做题时一键回看资料
- 按文件夹（含子文件夹）出题、错题回顾；标签筛选组卷
- 清单任务可设「今天 / 明天 / 每天 / 每周几」，支持推迟与跳过，完成需手动确认
- 旧版「科目/章节」「项目/分类」数据首次打开自动迁移

## 部署

本仓库通过 GitHub Pages 发布，入口为 index.html。
