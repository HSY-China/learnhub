# 学习空间 · 个性化学习系统

纯前端单文件应用，数据保存在浏览器本地（localStorage），不联网、无后端、无账号。

## 功能
- 首页：积分 / 等级 / 连胜 / 每日目标 / 薄弱点推荐
- 学习：科目 → 章节 → 章节测验（即时判分 + 解析）/ 错题回顾
- 计时学习：正计时 + 倒计时，结束即计入时长统计
- 时间统计：7 / 30 / 90 天趋势、科目占比、章节 TOP、时段分布
- 管理题库：单选 / 判断 / 多选，含解析，可编辑删除
- 支持导出 / 导入 JSON 备份

## 使用
打开页面即用。换设备时用「导出备份 / 导入数据」迁移进度。

## 部署
本仓库通过 GitHub Pages 发布，入口为 index.html。
