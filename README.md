# 学习空间 · 一站式个性化学习平台

纯前端单文件应用，数据保存在浏览器本地（localStorage + IndexedDB），不联网、无后端、无账号。

## 结构
以「学习项目」为中心，项目内包含两类内容，共用同一套分类与标签：

- 学习项目 → 📂 资料（PDF/PPT/Word/Excel/图片/音视频/网址/笔记）+ 📝 题目（单选/判断/多选，含解析）
- 资料 ↔ 题目 双向关联：可就某份资料出题，做题时一键回看资料

## 模块
- 首页：积分 / 等级 / 连胜 / 每日目标 / 薄弱项目与薄弱标签 / 资料概览
- 学习项目：项目列表 + 项目内 资料 / 题目 / 概览 三个标签页
- 资料库：跨项目资料总览、分类管理、导入导出资料包
- 计时学习：正计时 + 倒计时，可绑定项目
- 时间统计：7/30/90 天趋势、项目时长占比、时段分布、资料使用 TOP

## 使用
打开页面即用。旧版「科目/章节」数据会在首次打开时自动迁移（章节名转为标签）。
换设备用「导出备份 / 导入数据」+「导出(含文件)/导入资料包」。

## 部署
本仓库通过 GitHub Pages 发布，入口为 index.html。
